# Features Folder

```sh
<PROJECT ROOT>
|
+-- docs
|   |
|   +-- templates
|   |
|   +-- features # <-- YOU ARE HERE
|   |   |
|   |   +-- requirements
|   |   +-- work
+-- src
|   |
v   v
```

This folder contains folders for requirements and implementation documentation for the project.  Each feature should have its own markdown requiremt file in this directory's `requirements` subfolder and an implementation plan in this directory's `work` subdirectory.
